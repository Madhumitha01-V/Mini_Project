
Employee Management System

Technologies used:
*Frontend - HTML, CSS, JavaScript
*backend - node server.js
*database - Sqlite

Features:
*We can add,update,delete or view the employee's name,email,department and salary in the table

Backend Working:

*Open terminal inside backend folder:
*npm install
*Run server:
*node server.js
*Server runs on:
*http://localhost:3000

Frontend Working:
Open frontend/index.html in browser.
